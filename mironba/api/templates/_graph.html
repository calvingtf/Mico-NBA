What the colours honestly say. Disposition is read off the record, never recomputed here: the cascade's counterparty gate admits only SELLER teams, so a team recorded as a counterparty was seller-classified at run time and an acquirer passed the not-a-seller gate. A team that did not participate is unclassified — the artifact does not say, and this page does not guess. Positions are fixed geography, not a force layout: a layout that rearranged per load would make two runs impossible to compare. Node size is payroll from this run's own reaction record; the bars in the hover card mark the published cap, tax and apron lines for {{ g.season }}.
